# Mi Universo ♡

Página estática optimizada para celular/iPhone.

## Archivos

- index.html — página principal
- style.css — diseño y animaciones CSS
- script.js — estrellas, partículas, meteoros, parallax y botón
- assets/timeless.mp3 — coloca aquí la canción que quieras usar

## Publicar

Sube TODOS los archivos manteniendo exactamente esta estructura:

mi-universo/
├── index.html
├── style.css
├── script.js
└── assets/
    └── musica.mp3

La página se abre desde cualquier iPhone mediante una URL HTTPS cuando la publiques en un servicio de páginas estáticas.

## Cambiar el mensaje

Edita el texto dentro de:

<div class="text">
  ...
</div>

## Música en iPhone

La música está programada para intentar comenzar al tocar ENTRAR ♡.
Safari/iOS bloquea el autoplay que intenta iniciar audio sin interacción del usuario.


Las frases aparecen una por una y cada frase dura aproximadamente 5 segundos.
